# Проверка диапазона версий движка — 24 октября 2026

Официальные архивы 1.12.2, 1.13.21 и 1.14.3 получены обновлённым скриптом с проверкой digest GitHub release asset; 1.12.12 использует ранее сверенную официальную фикстуру. Проверки включают `check` для всех трёх типов прокси и шести конфигураций стенда, настоящий loopback UDP через авторизованный SOCKS upstream, отсутствие Direct fallback при отказе UDP и завершение дочернего процесса Windows Job Object.

Windows CI настроен на все четыре версии, но удалённый workflow в этой сессии не запускался. Ветка 1.15 и будущие выпуски не испытывались реальным бинарником: для них предусмотрена версия-зависимая генерация без поля TUN stack и обязательный `check`. Живой TUN по-прежнему не запускался из-за конфликтующих VPN-маршрутов и отсутствия административных прав. Эти результаты подтверждают проверенную совместимость конфигурации и лабораторного трафика, а не полную сетевую приёмку Windows.

Инструкция: [совместимость движка](engine-compatibility.md).

Опубликованная portable-сборка прошла UI smoke и сформировала 12 снимков (6 вкладок, две темы); форма настроек проверена визуально. Подготовка опубликованного сетевого стенда успешно завершилась с 1.12.2 и 1.14.3 без создания TUN.
