# PathFlux branding

`pathflux-logo.png` — прозрачная адаптация предоставленного пользователем неонового логотипа. Используется в шапке приложения. `pathflux.ico` — тот же знак в размерах 16, 20, 24, 32, 40, 48, 64, 128 и 256 px для EXE, окна и системного трея. Пересборка контейнера ICO без изменения рисунка: `./scripts/build-app-icon.ps1` на Windows.

Адаптация выполнена встроенным инструментом imagegen. Исходное изображение пользователя не изменено. Запрос:

> Edit the supplied PathFlux logo into a polished small desktop application icon. Preserve the recognizable P silhouette, three input nodes on the left and two flowing arrows pointing right inside the P. Keep cyan to electric blue to violet gradient. Remove the entire dark rounded square tile, border, background and external glow: actual transparent background. Simplify the bevels into crisp smooth bold shapes with subtle highlights, less 3D, high contrast, generous clear negative spaces between the streams so it is readable at 24 pixels. Single centered symbol filling about 88% of a square canvas, no text, no shadow, no duplicate icons. This is a faithful refined adaptation of the supplied mark, not a redesign.
