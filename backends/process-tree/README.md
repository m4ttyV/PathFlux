# PathFlux Process Tree backend

Экспериментальная Windows x64 сборка на основе sing-box v1.14.3. Это модифицированный движок, а не официальный выпуск. По умолчанию в PathFlux выключен; установка рабочего движка автоматически не изменяется.

Область подтверждения, ограничения, сборка и NetworkLab: [техническое описание](../../docs/process-tree-backend.md).

`tree.go` и `native_windows.go` — атрибуция экземпляров и предков; `overlay/` — интеграция с исходниками sing-box. `prepare.ps1` требует свежие исходники с ожидаемыми точками применения; `build.ps1` самостоятельно проверяет закреплённый архив, распаковывает его в новый каталог и собирает результат с полными изменёнными исходниками и лицензией upstream.

Этот backend и overlay предназначены для совместного распространения с sing-box на условиях GPL-3.0-only. Лицензия upstream копируется сборкой в `LICENSE.sing-box`; модифицированные исходники находятся рядом в `source/`. Это не меняет лицензионные условия остальных компонентов PathFlux. Публикация сборки и аудит всех транзитивных лицензий не выполнялись.
